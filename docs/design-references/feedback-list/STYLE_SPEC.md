# Feedback List Style Specification

## 1. 整體版面

| 項目         | 規格                                     |
| ------------ | ---------------------------------------- |
| 頁面背景     | `#F6F8FB`                                |
| 頂部識別線   | `2px solid #25282D`                      |
| 桌面頁面內距 | 上 `31px`、左右 `28px`、下 `48px`        |
| 行動頁面內距 | 上 `23px`、左右 `16px`、下 `40px`        |
| 群組間距     | 桌面 `24px`、行動 `20px`                 |
| 字體         | Inter → system sans-serif → Noto Sans TC |

## 2. 工具列

| 項目         | 規格                            |
| ------------ | ------------------------------- |
| 頁面標題     | `14px / 18px`、`700`、`#101827` |
| 標題下距     | `17px`                          |
| 動作按鈕高度 | `36px`                          |
| 動作按鈕圓角 | `6px`                           |
| 動作按鈕底色 | `#18181B`                       |
| 動作按鈕文字 | `14px`、`700`、白色             |
| 按鈕間距     | `8px`                           |
| 搜尋框       | `286 × 36px`、圓角 `6px`        |

工具列在交付元件中只負責呈現外觀，不可加入互動。

## 3. 大型表格卡片

| 項目         | 規格                             |
| ------------ | -------------------------------- |
| 外框         | 無                               |
| 圓角         | `6px`                            |
| 背景         | `#FFFFFF`                        |
| 陰影         | `0 5px 16px rgb(15 23 42 / 11%)` |
| 最小表格寬度 | 桌面 `1000px`、行動 `940px`      |
| 水平溢位     | 可捲動，原生滾軸隱藏             |

## 4. 群組標題

| 項目       | 規格                              |
| ---------- | --------------------------------- |
| 高度       | 最小 `58px`                       |
| 內距       | 上下 `10px`、左 `12px`、右 `14px` |
| 新貼文底色 | `#DFE9F5`                         |
| 待討論底色 | `#EEE5D9`                         |
| 標題與數量 | `15px / 20px`、`700`、`#101827`   |
| 拖曳 icon  | `15 × 15px`、`#A3ABB7`            |
| 內容間距   | `10px`                            |
| 下框線     | 無                                |

整個群組標題列是群組拖曳區。拖曳時游標使用 `grab/grabbing`。

## 5. 欄位表頭

| 項目     | 規格                     |
| -------- | ------------------------ |
| 高度     | 最小 `38px`              |
| 底色     | `#F7F8FA`                |
| 文字     | `12px`、`500`、`#687281` |
| 上下框線 | 無                       |
| 左右內距 | `21px`                   |
| 欄距     | `22px`                   |

欄位順序固定：

1. 標題 / 描述
2. 分類
3. 負責人
4. 互動
5. 更新時間

桌面欄寬：

```css
grid-template-columns:
  minmax(220px, 1.55fr)
  minmax(245px, 1.05fr)
  minmax(140px, 0.68fr)
  minmax(145px, 0.66fr)
  minmax(135px, 0.55fr);
```

| 項目      | 規格                     |

## 10. 互動與時間

| 項目            | 規格                        |
| --------------- | --------------------------- |
| 留言文字        | `12px`、`#737D8D`           |
| 留言 icon       | `14 × 14px`、線條 `#9AA2AE` |
| icon 與文字間距 | `5px`                       |
| 互動區寬度      | `fit-content`               |
| 右內距          | `0`                         |
| 更新時間        | `12px`、`500`、`#485162`    |

## 11. 唯一允許的互動：拖曳

### 群組拖曳

- 從群組標題列開始。
- 可交換群組順序。
- Drop 目標顯示深色頂部提示。

### 清單拖曳

- 整列皆可作為 drag source。
- 可在同群組內重新排序。
- 可跨群組移動。
- 不顯示清單拖曳 icon。

### 禁止的互動

- 新增 Feedback
- 新增篩選
- 搜尋
- 展開／收合
- 負責人選取
- 欄位排序
- 編輯、刪除、分頁

## 12. 驗收規格

1. 視窗寬度足夠時，五欄不得互相重疊。
2. 寬度不足時表格可以水平移動，且看不到原生滾軸。
3. 兩個群組標題使用不同、固定的柔和色，不可每次 render 隨機跳色。
4. 卡片沒有最外層灰框，但陰影與 `6px` 圓角清楚可見。
5. 群組標題與欄位表頭皆沒有上下分隔框線。
6. 分類標籤不可出現字母 icon。
7. 清單列不可出現拖曳 icon，但整列仍可拖曳。
8. 群組拖曳與清單拖曳不可互相誤觸。
9. 清單項目可跨群組移動，資料不遺失。
10. 除拖曳外，參考元件不可有其他會改變 state 的 UI 操作。
