# Roadmap 視覺與互動規格

## 1. 樣式目標

以本次確認的 Roadmap 頁面為準：灰藍頁面底色、透明的標頭／Tab／工具列、帶左右留白的連續白底看板。卡片為 Linear 風格的緊湊白底卡片，**不是彈窗**。

整頁包含：標題與說明 → 新增 Feedback 展示按鈕 → 三個 Tab 與圓形加號 → 同區下排工具列 → 五個展開欄位。工具列與 Tab 之間保留細線，外層無白底／外框。

## 4. 互動規格

### 卡片跨欄拖曳

- 只接受本看板的 `application/x-roadmap-style-card` JSON payload。
- 開始時來源卡片 `opacity: 0.55`，顯示瀏覽器原生拖曳影像。
- 有效目標欄位改為淡紫底與 1px inset 框；離開、取消、放下後清除。
- 放到另一欄：只改 `columnId`，來源／目標數量更新，卡片狀態圖示跟隨欄位，標籤／標題／負責人不變。
- 放回原欄、無效 JSON、未知卡片、其他看板 payload：不移動、不新增、不刪除、不發通知。
- 狀態只保留於當前掛載，不做重新整理後的儲存。

### 看板左右捲動

- 只捲動 `.rm-viewport`；超出內容裁切於看板左右留白內，不能撐寬宿主頁面。
- `overflow-x: auto` 保留；用 `scrollbar-width: none` 與 WebKit scrollbar 規則隱藏捲軸。
- 有溢出才顯示箭頭；到左端停用左箭頭、到右端停用右箭頭。邊界容差 1px。
- 每次箭頭捲動一欄的**實際寬度**，不是固定卡片寬；一般平滑，減少動態效果時立即捲動。
- 箭頭位於看板左右邊界：桌面距外側 `33 - 18 = 15px`；≤800px 距外側 2px。上距 `min(50%, 320px)`。
- 滾輪採 `deltaX` / `deltaY` 絕對值較大者，轉為水平位移；line mode 乘 16，page mode 乘可視寬度，pixel mode 原值。
- `Ctrl + wheel` 不攔截；沒有溢出、零位移、已在該方向邊界時不阻止預設動作。
- 觸控板水平手勢與原生觸控水平捲動可用。
- 聚焦捲動容器後左右鍵移一欄、Home / End 到起點／終點；不攔截其他子控制項的按鍵。
- ResizeObserver 重新判斷是否溢出；寬螢幕放得下五欄時兩箭頭一起消失。

### 其他元素

全部只展示外觀：新增 Feedback、Tab／加號、狀態 select、發佈、設定、搜尋、篩選、欄位選單／加號、卡片更多選單、空欄新增區。必須 disabled，且不以 disabled 預設灰階改變原本外觀。

## 5. 驗收清單

- [ ] 四個檔案可獨立搬入其他 React 專案；只引用 React 與同資料夾 CSS。
- [ ] 不依賴原頁面 `src/index.css`、Tailwind、全域 reset 或原 App 狀態。
- [ ] 1568px 視窗時看板左右各 33px；≤800px 時各 16px。
- [ ] 白底連續、五欄順序正確、四條灰色分隔線、無欄間 gap。
- [ ] 所有卡片 ≥300px，所有欄位 ≥333px；不可在手機上壓窄。
- [ ] 溢出只發生在看板內；實際水平捲動可用、捲軸不可見。
- [ ] 左右箭頭會捲動、正確停用；1920px 預設寬度能放下五欄時不顯示。
- [ ] 滾輪正反方向、觸控板 deltaX、line/page 模式、Ctrl + wheel 不攔截均符合規格。
- [ ] 拖曳到另一欄、放回原欄、移出看板取消、非法 payload 均正確。
- [ ] 移動不遺失卡片／標籤／負責人，不產生重複卡片，數量與狀態圖示同步。
- [ ] 預設卡片 FB-1132 的頭像不顯示，頁尾「由 歐瑜 提出」仍保留。
- [ ] 所有非白名單控制項不可操作，卡片標題不是輸入框。
- [ ] 重新整理還原示範資料；沒有 API / storage 請求，不宣稱持久化。
- [ ] 兩個獨立看板的拖曳與捲動互不影響；卸載後無殘留事件。
- [ ] 系統偏好減少動態效果時不做平滑捲動。
- [ ] 文字、圖示、禁用狀態可被輔助技術辨識；卡片拖放仍為桌面指標功能，不宣稱完整鍵盤／手指拖放。
