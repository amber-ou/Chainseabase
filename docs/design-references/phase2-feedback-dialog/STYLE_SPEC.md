# Feedback 樣式規格與驗收

以下為目前確認的畫面數值。CSS 為準，不以 shadcn 預設色替換。

## 整體

- 白色彈窗，內容自然撐高，不能保留舊的 699px 最小高度。
- 預覽：視窗寬度 ≥1000px 時，彈窗最大寬 894px、外側空間 24px、置中；背景 `#eef1f5`。
- 正式整合：沿用既有 Radix／shadcn 彈窗定位、overlay 和外層圓角。
- 8px 外層圓角只存在於預覽版的桌面容器規則，不得據此改動正式彈窗既有圓角。
- 字型順序：Arial、Noto Sans TC、PingFang TC、Microsoft JhengHei、sans-serif。正式專案可對接既有等效字型 token。

## 小螢幕（≤640px）

- Header 左右 padding 改為 17px。
- Body、Footer 左右 padding 改為 18px。
- 標題文字改為 19px，描述最小高改為 120px。
- 膠囊維持自動換行，不改成三欄卡片，不強制單行橫向捲動。

## 驗收清單

- [ ] 整個 Feedback 彈窗已套用，而不是只改 Header。
- [ ] 標題列有灰色底線；最外層圓角保持原樣。
- [ ] 標題與描述沒有框線，文字、placeholder 均灰色。
- [ ] placeholder 是空白時的提示，不是預填表單值。
- [ ] 描述下方只有圖片 icon 按鈕，灰底。
- [ ] 圖片按鈕與標籤列間距 8px。
- [ ] 只顯示四顆膠囊，沒有優先級與版本。
- [ ] 狀態、類別、Person tag、加入標籤四顆膠囊高度均為 32px；不擴大套用至其他按鈕。
- [ ] 「＋」無虛線、灰底、高 32px。
- [ ] 作者／時間在膠囊下方，不在內容上方。
- [ ] Footer 取消灰底、建立黑底白字；兩顆維持 29px 高。
- [ ] 沒有 Tab、公開範圍、Markdown 說明文字。
- [ ] 320px／390px 沒有橫向溢出；彈窗高度隨內容。
