## 被取代的舊方案

- 2026-10-28：舊「必須雲端」、匿名前台及 Vercel／Supabase 正式架構已被 Windows 原生方案取代。WSL／Docker 方案不採用。
- Roadmap 不再提供同一欄跨狀態／類別／Tag 的 AND／OR。
- 不再允許拖曳一次修改版本與優先級等多個維度。
- 不再使用最左符合欄位優先或拖曳後固定歸屬；資料值本身唯一決定欄位。
- 優先級仍是 Feedback 欄位，但不是第一版 Roadmap 分欄維度。
- Personal 不再提供條件式欄位或 OR／AND。
- Product 不再是純空白 Dashboard，已包含 Calendar。
- Calendar 不採僅嵌入或僅唯讀方案。
- 不要求應用實作前再確認已批准的上述規則。

## 工程預設，非逐項使用者指定

以下為完成可開發規格而選定，若實作證據需調整，應保留產品意圖並同步文件：

| 項目 | 本版預設 |
| --- | --- |
| App 路由／網域 | 同一 Next.js 應用兩個 host，host-only session cookie。 |
| 身分實作 | 伺服器管理的 Google OAuth／OIDC session；可用成熟 auth library，實作時鎖版。 |
| 邀請有效期 | 7 天、Email 綁定、一次性雜湊 token。 |
| 文字 | 標題 200、描述 20,000、留言 5,000 字元；Unicode 字元計數，trim 後驗證。 |
| 優先級 | P0 非常重要、P1 重要、P2 一般、P3 低。 |
| 編輯器 | 基本 Markdown、禁止原始 HTML；不含 Feedback 圖片與附件。 |
| 刪除 | Feedback／普通留言與可見操作紀錄採軟刪除；不得復活已清空內容。 |
| 前台欄位 | 只傳公開資料清單；版本、Person tag、優先級、一般內部 Tag 不公開。 |
| Roadmap 發布 | 顯式發布、預設內部；第一版只發布狀態看板。 |
| 公開 Feedback 的普通留言 | 全部公開，後台輸入時標示；Schedule 僅內部。 |
| 測試者移除內容 | 可編輯自己的文字；移除由團隊處理。 |
| 時間排序 | created_at DESC、id DESC 作穩定次序。 |
| Personal 卡片離開責任範圍 | 移除私人位置；之後再次負責時進預設欄。 |
| 重複日曆新增 | 每日／每週／每月基本規則與結束設定；無法無損編輯的外部規則只讀並連結 Google。 |
| 活動提醒 | 不新增提醒管理 UI，沿用日曆預設；更新時保留既有提醒設定。 |
| Polling | 後台前景 30 秒通知、60 秒日曆，背景暫停，錯誤退避。 |
| 技術工具 | TypeScript、Next.js、PostgreSQL；具體相依版本待實作時選受支援版本並鎖定。 |
